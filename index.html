FAQ

자주 묻는 질문

설치 파일(.exe / .dmg)을 따로 설치해야 하나요?

아니요. 압축 파일 안의 HTML 파일(예: solodesk-studio.html 또는 staydesk-pro.html)을 더블클릭하면 크롬·사파리·엣지 브라우저에서 1초 만에 바로 실행됩니다. 인터넷이 끊긴 환경에서도 정상 작동합니다.

브라우저 캐시를 지우면 입력한 데이터가 사라지나요?

브라우저 로컬 스토리지에 자동 저장되며, 앱 상단의 [JSON 백업 다운로드] 버튼을 누르면 모든 데이터가 파일 1개로 저장됩니다. 월말이나 중요 작업 후 백업 파일을 보관해 두시면 다른 PC에서도 1초 만에 복원할 수 있습니다.

세금 계산기나 용역 계약서 서식은 법적 효력이 있나요?

제공되는 3.3%·부가세 계산기와 표준 용역 계약서 서식은 프리랜서 및 사업자의 실무 편의를 돕는 참고용 도구입니다. 실제 세무 신고 금액은 국세청 홈택스·세무사 기준을 따르며, 고액·특수 계약은 법률 전문가 검토를 권장합니다.

구매 후 어떤 파일들을 받게 되나요?

실행용 단일 HTML 완제품 파일과 30초 세팅·PDF 출력 팁이 담긴 사용 가이드 PDF가 포함된 ZIP 패키지를 즉시 전달받습니다.
